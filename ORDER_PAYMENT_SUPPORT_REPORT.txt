LUNÉRA — ORDER, PAYMENT & CUSTOMER SUPPORT STATUS
Updated: 10 November 2026

CURRENT STORE SETUP
- Storefront is hosted on GitHub Pages.
- Firebase Authentication supports customer accounts and verified admin access.
- Firestore stores the shared catalogue at site/catalogue and customer orders in orders.
- Customers must be signed in to place an order. Each order is associated with the authenticated Firebase UID.
- The Manage panel is restricted to the verified admin account lunerastore26@gmail.com.
- Manage catalogue changes are saved to Firestore before the browser cache is updated.
- Checkout is COD-only. Razorpay is intentionally not enabled in the customer checkout.
- Product, category cover and hero image uploads use Cloudinary. The Manage editor uses 1005:563 for homepage hero/collection covers and 4:5 for product photos and founder portraits.
- EmailJS order notification is attempted after the order is saved. An email failure does not cancel the saved COD order.

IMPORTANT LIMITATIONS
1. This repository contains firestore.rules, but the deployed Firebase Console rules cannot be verified from GitHub. Publish the exact repository rules in Firebase Console > Firestore Database > Rules.
2. GitHub Pages is static hosting. Firebase Authentication and Firestore provide the shared account/order data; no private application server runs on GitHub Pages.
3. Checkout revalidates product IDs, prices, sizes and quantities against the shared catalogue in the client before saving. Firestore rules restrict order ownership and admin updates, but they do not independently perform a full server-side catalogue price calculation for arbitrary direct Firestore writes. Do not describe the current COD flow as fraud-proof.
4. Historical orders created before userId was added may not appear in a customer's account history.
5. No online payment is collected in checkout. Do not mark an order paid from a browser redirect, screenshot or customer message. A future payment launch must use a server-side endpoint and verified gateway signatures.
